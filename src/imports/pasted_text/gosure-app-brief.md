Design and build a modern mobile-first travel safety app called “GoSure”.

APP PURPOSE:
GoSure is a solo travel safety app for people traveling from one city to another for tourism, work, education, religious visits, trekking, or personal reasons.

The app helps travelers:
- Check destination safety
- Find safe routes
- Identify unsafe areas
- Find trusted transportation
- Share live location
- Get emergency SOS assistance
- Find nearby police and hospitals
- Access travel safety tips
- Manage trusted contacts
- Track journey history

UX REQUIREMENTS
==================================================

The app must:

- Be mobile-first
- Have simple navigation
- Use consistent spacing
- Use accessible typography
- Use large touch targets
- Keep SOS easily accessible
- Clearly distinguish SAFE / CAUTION / UNSAFE
- Avoid information overload
- Provide loading states
- Provide empty states
- Provide error states
- Provide success states
- Provide confirmation modals
- Make interactions functional
- Use realistic sample data

The main journey flow should be:

Start
→ Enter Destination
→ Check Destination Safety
→ Check Unsafe Areas
→ Select Safe Route
→ Check Route Safety

If route is SAFE:
→ Choose Trusted Transport
→ Start Journey
→ Share Live Location
→ Follow Navigation
→ Reach Destination
→ Check-in SAFE
→ End

If route is NOT SAFE:
→ Show Alternative Safe Routes
→ Select Another Route
→ Check Route Safety again

Make the final UI look like a polished real-world travel safety application suitable for a professional UI/UX portfolio case study.

Maintain the GoSure brand identity and use the exact HEX color codes provided above consistently throughout the application.
